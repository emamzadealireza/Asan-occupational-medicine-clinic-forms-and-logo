# Asan Occupational Medicine Clinic — Forms & Logo

A collection of HTML form templates and branding assets for the Asan Occupational Medicine clinic, stored here for safekeeping and future sharing.

## Contents

| File | Description |
| --- | --- |
| `clinic consult form.html` | Clinic consultation form template |
| `Prescription Form.html` | Prescription form template (سرنسخه) |
| `logo-final-base64.txt` | Final clinic logo as a Base64 data string (without text) |

## Usage

The HTML files are self-contained templates and can be opened directly in any browser or imported into other projects as needed. The logo file is a Base64-encoded string that can be embedded directly into HTML/CSS as a data URI.
